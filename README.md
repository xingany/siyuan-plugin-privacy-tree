# 文档树隐私保护（Privacy Tree）

一键隐藏思源中的各种名称与内容，适合演示、截图或在他人在场时保护隐私。

## 功能

- **顶栏按钮**一键切换隐私模式（顶栏右侧「盾牌」图标，开启时高亮）。
- **两个快捷键**：
  - `Ctrl+Shift+Z` 隐藏（可编辑）
  - `Ctrl+Shift+X` 隐藏（不可编辑：整屏拦截，点击/按键都要密码）
  - 可在「设置 → 快捷键」中搜索“隐私模式”自定义。
- **名称遮盖**：左侧文档树 / 顶部页签 / 文档大标题 / 窗口标题。
  - 默认名称：未单独命名的条目统一用它（默认 `••••••`）。
  - 笔记本（项目）别名：每个笔记本单独命名。
  - 文档别名：右键文档树中的文档，或在设置里直接命名「当前文档」。
  - 未命名文档别名：统一处理「未命名文档」等条目。
- **内容遮盖**（针对当前打开的文档）：可隐藏整篇正文或指定块（段落/标题/列表/表格等）；
  - 遮盖形式：覆盖白条 / 指定文字 / 随机文字。
  - 需要先「启用内容遮盖」并「选择要隐藏的内容」才会生效。
- **标题遮盖**：正文中的 h1–h6 标题与右侧大纲。
- **安全与自动**：
  - 密码解锁：退出隐私模式需输入密码（可开关）。
  - 不可编辑：隐私模式下点击任意处都需密码才能操作（页面仍显示）。
  - 空闲自动进入：N 分钟未操作自动开启隐私模式。
  - 自动收起文档树：进入隐私模式 N 分钟后自动收起左侧文档树（避免暴露文档数量），退出时自动展开。
- 关闭插件时自动退出隐私模式，避免残留。

## 使用

1. 点击顶栏图标，或按 `Ctrl+Shift+Z` / `Ctrl+Shift+X`。
2. 设置面板：右键顶栏图标 → 「文档树隐私保护设置」，按分组卡片操作。
3. 内容隐藏：设置 → 「内容遮盖」→ 勾选「启用内容遮盖」→「选择要隐藏的内容」/「隐藏当前整篇文档」。

## 隐私说明

- 所有设置与别名仅保存在**本地**插件数据目录中，插件不会上传任何笔记内容。
- 密码以明文保存在本地插件数据文件（`data/storage/petal/<插件名>/config.json`），属于界面锁级别，不是强加密。

## 已知限制
