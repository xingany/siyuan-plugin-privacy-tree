# 文档树隐私保护（Privacy Tree）

一键隐藏左侧文档树中的**笔记本（项目）名称**和**文档名称**，用占位内容或自定义别名替代，适合演示、截图或在他人面前保护隐私。

## 功能

- 顶栏按钮一键切换隐私模式（顶栏右侧「盾牌」图标，开启时高亮）
- 快捷键切换：默认 `Alt+Ctrl+P`（Windows）/ `Option+Command+P`（Mac），可在「设置 → 快捷键」中搜索「切换文档树隐私模式」自定义
- **统一占位内容**：没有单独设置别名的条目统一显示为默认占位文字（默认 `••••••`）
- **笔记本（项目）别名**：右键顶栏图标 → 设置 → 「笔记本（项目）别名」，为每个笔记本单独起显示名
- **文档别名**：在文档树中**右键某个文档** → 「设置隐私别名…」
- 文档树右键菜单里也有「开启/关闭隐私模式」和「设置」入口
- 关闭插件时自动退出隐私模式，避免残留

## 使用

1. 点击顶栏图标或按快捷键，开启隐私模式。
2. 给单个文档起假名：文档树中右键该文档 → 设置隐私别名。
3. 给笔记本起假名：右键顶栏图标 → 设置 → 笔记本（项目）别名。
4. 设置面板里可统一修改默认占位内容、管理/删除别名。

## 快捷键符号说明

`⌘` = Windows 的 Ctrl / Mac 的 Command；`⌥` = Windows 的 Alt / Mac 的 Option；`⇧` = Shift。
Windows 上 `⌥⌘P` 即 `Alt + Ctrl + P`。不习惯可直接在「设置 → 快捷键」里按组合键重设。

## 已知限制

- 目前仅遮罩文件树中的名称；文档标题栏、页签、鼠标悬浮的原生 tooltip 暂未处理。
